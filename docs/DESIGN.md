# 디자인 설계 — Kirogi (Monad)

> **2026-09-27 방향 확정:** 이름·마크는 기러기(CTC) 그대로. 토큰·타이포·톤은 기러기 DNA(`design/kirogi-dna.html`) — 방향=색(보내는 쪽 #8fa6ff → 가족 쪽 #f0b36b, 정산 #46cf95), Archivo 선언형 제목, 1px 선, 증거 우선. 아래 토스 원칙은 UX 뼈대로만 유지.
>
> **데모 시나리오 확정 (달러 기준):** 서울에서 일하는 아빠 → LA에서 공부하는 지우. 용도 = 학비(학교 한 곳)·월세(집주인)·식비(마트). 제품 자체는 통화·가맹점·용도를 설정으로 바꿀 수 있게 국가 중립으로 만든다. (아래 베트남 시나리오는 초기안)

## (초기) 가칭 Earmark — "용도를 정해 보내는 송금"

> 원칙은 토스에서, 정체성은 우리 것으로, 에셋은 Codex 로.
> 토스의 **원칙·패턴만** 참고한다. 토스 로고·Toss Product Sans·토스페이스·토스 파랑·화면 복제는 쓰지 않는다.

## 1. 제품 한 줄
해외에서 일하는 가족이 고향으로 돈을 보낼 때 **어디에 쓸지(식료품·학비·병원·교통)를 정해서** 보내고,
가족이 동네 가게에서 QR 로 결제하면 **가게는 1초 안에 정산**받고 **보낸 사람은 바로 영수증**을 받는다.
시나리오: 한국에서 일하는 베트남 노동자 → 호찌민의 가족 (데모 기준)

## 2. 사용자 3명 (앱 3면)
| 역할 | 핵심 질문 | 화면 |
|---|---|---|
| 보내는 사람 (한국) | "보낸 돈이 약속한 데 쓰였나?" | 송금하기 · 사용처 정하기 · 실시간 영수증 |
| 받는 가족 (고향) | "어디서 쓸 수 있지? 얼마 남았지?" | 잔액·사용처별 한도 · QR 결제 |
| 가게 | "돈이 진짜 들어왔나?" | 결제 받기(QR) · 정산 확인 |

## 3. 근거로 삼는 토스 원칙
**TDS:** "한 화면에서 유저가 해야 할 단 하나의 액션이 선명하게 드러나고 있나요?"
→ 화면마다 질문 하나 + 하단 전체 너비 버튼 하나.

**라이팅 8원칙** (toss.tech/article/8-writing-principles-of-toss)
1. 다음 화면을 예측할 힌트 2. 군더더기 단어 제거 3. 빈 문장 제거 4. 핵심 메시지만
5. 쉬운 말 6. 강요 대신 제안 7. 누구나 이해하는 말 8. 숨은 감정에 공감

**적용 패턴**
- 질문형 큰 제목: "얼마를 보낼까요?" / 부가 설명은 작은 회색 한 줄
- 금액은 큰 숫자 + 숫자 키패드, 빠른 버튼(+1만·+5만·+10만)
- 회색 배경 위 흰 카드, 넉넉한 여백(8pt 그리드), 모서리 16–20px
- 포인트 색은 행동 버튼에만. 나머지는 회색조
- 보내기 전 확인 화면(받는 사람 이름·환율·도착 금액), 완료 화면은 결과 한 문장 + 체크 모션
- 크립토 단어 숨김: 지갑·가스·USDC·트랜잭션 → "잔액", "보냈어요", "영수증" (기술 정보는 '자세히 보기' 안에만)
- 불안 줄이기: "가게에 바로 들어갔어요 · 0.8초" 처럼 결과와 시간을 명시 (← 왜 Monad 인지 보여주는 장치)

## 4. 핵심 화면 5개 (1차)
1. **송금하기** — 받는 사람 → "얼마를 보낼까요?"(원화 입력, 도착 금액 동 표시) → 확인
2. **사용처 정하기** — "어디에 쓰게 할까요?" 카테고리 칩(식료품·학비·병원·교통) + 칩별 한도 슬라이더, 기한("안 쓴 돈은 30일 뒤 돌려받아요")
3. **가족: QR 결제** — 사용처별 남은 금액 카드 → 가게 QR 스캔 → "식료품 한도에서 결제할게요" → 완료
4. **가게: 결제 받기** — 금액 입력 → QR 표시 → "들어왔어요 · 0.8초"
5. **보낸 사람: 실시간 영수증** — 알림 + 타임라인("엄마가 Bách Hóa Xanh 에서 식료품 ₫350,000 썼어요")

## 5. 디자인 토큰 (기본값, 브랜드 확정 후 교체)
- 글꼴: **Pretendard** (무료 OFL) — 토스 전용 글꼴 대체
- 회색: #F2F4F6 배경 / #E5E8EB 구분선 / #8B95A1 보조 텍스트 / #191F28 본문
- 크기: 제목 26/Bold, 금액 34/Bold, 본문 17, 보조 14
- 간격 8pt, 카드 radius 20, 버튼 높이 56 radius 16
